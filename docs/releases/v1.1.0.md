# Travel Copilot v1.1.0

Travel Copilot 将旅行想法和已有行程整理成经过讨论确认的结构化计划，再生成可分享的互动 HTML 与个人 ICS 日历提醒。

## 包含内容

- 行程审查与补漏、用户确认、Visual Director 视觉选择工作流。
- 通用 Python 渲染器、五个基础主题、时间轴、Now/Next、地图导航、本地清单与完成状态。
- 多同行人 ICS 导出与标准旅行包生成。
- Claude Code、Codex、WorkBuddy、通用 Agent Skills 安装指南。
- MIT 许可证、第三方 NOTICE、贡献指南、脱敏 Demo 和截图目录规范。

## 下载与使用

下载 `travel-copilot-v1.1.0.zip`，解压完整 `travel-copilot` 目录，按 `docs/installation.md` 安装。建议 Python 3.9+，脚本只用标准库；直接查看 `examples/demo-trip.html` 无需 Python。

`SHA256SUMS.txt` 可用于检查下载完整性。GitHub 自动生成的 Source code ZIP 与此手动打包附件可能不同，以相应附件校验值为准。

## 兼容性与限制

保留 `trip.json → 共享 Python 渲染器 → HTML / ICS` 跨平台架构。视觉渲染器仍含日本路线与日期文案，作为实验性模板保留；通用旅行推荐基础渲染器。包内不包含先前演示的完整日本视觉页面及对应照片/brief。

HTML 不提供关页后通知或电话提醒；ICS 导入需在目标日历核对。地图/照片需联网，导入的日历不会自动同步更新。客户端端到端兼容性未全部实机验证，详见 `docs/known-limitations.md` 和 `docs/validation.md`。
