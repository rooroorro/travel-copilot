# v1.1.0 已知限制

以下基于原始压缩包的源码审查，不将设计目标等同于已交付能力。

## 视觉模板

`visual_template.html` 保留 JAPAN 标题、日本城市线路、3 人 8 天文案、HIKARI 角色以及特定日期的箱根/奈良提示。部分 brief 字段只作为描述，不会动态重建布局、角色和动画。它也没有基础渲染器的 Now/Next 卡片。应将其视为实验性日本主题模板；面向其他目的地使用基础渲染器。原包无可复现的完整日本视觉 Demo / brief / 照片归属清单。

## 日历与时间

- 导入 ICS 后，HTML 更新不会同步到日历；重复导入可能产生重复提醒。
- 各日历对 `TZID`、`VALARM`、中文长行支持不同。当前 ICS 未包含 `VTIMEZONE` 定义，也未执行长行折叠。发布检查只验证导出结构，不能代替手机端导入验收。
- UID 以事件 ID 生成，多个旅行复用同一 ID 可能在日历中冲突；不同旅行请使用唯一事件 ID。
- Python 导出器的普通行程事件只选 P0/P1；浏览器可选 P2，二者范围并非完全一致。
- 基础 Now/Next 按设备当前时间及旅行时区显示；只有时间不确定或跨午夜的活动需要人工检查。

## 浏览器、离线与校验

- `localStorage` 依赖浏览器对本地文件的支持；无痕、存储被禁用或清理数据时不能保证持久保存。
- 视觉模板使用较宽泛的存储键，多个行程页面可能共享完成状态。
- 动画、CSS `color-mix` 等需要较新的浏览器；系统减少动态效果设置并不代表每处 JavaScript 地图动画都已禁用。
- 文字行程可离线阅读，远程库/瓦片/照片需要网络。未承诺地图服务可用性。
- 校验器检查基本结构，未全面验证时区有效性、行程重叠、所有日期范围或外部链接安全。
- 只应打开可信来源的生成 HTML；导入/渲染非可信 JSON 和 brief 前需审查内容。当前渲染器不是安全隔离器。
