# Research guide

Use current web/connected tools when a fact can change or materially affects feasibility: opening days, holiday closures, transport disruptions, official reservation windows, weather, event schedules, entry rules.

Prefer official sources for operational facts. Community sources are useful for experience and qualitative tips, not as the sole authority for rules or schedules.

For coordinates, use a trustworthy geocoding/map source. Record source coordinate system. If using Chinese GCJ-02 coordinates with OSM/Leaflet, convert before plotting or use a compatible map source.

Avoid false precision:

- If travel time varies, use a range/buffer.
- Do not present stale prices as guaranteed prices.
- Do not fabricate ratings or photos.
- If a fact cannot be verified, say it is unverified and keep the plan usable without it.

The final HTML should distinguish stable itinerary decisions from volatile operational facts with a “verify before departure” note.
